# Reports

The committed `proxmox-preflight`, `cluster-status`, and `guest-connectivity` Markdown/JSON/CSV files are initial status snapshots. They clearly show which live checks are `NOT RUN` or `BLOCKED`; they are not evidence of successful provisioning. Regenerate them on the actual lab host after running the scripts.

Live reports are generated by scripts on the host/LAN where checks run. Each live check records a timestamp and explicit status. A missing live report means the check has **not run**; it does not mean success.

Generated, potentially sensitive reports should be stored under `reports/generated/` (ignored by Git). Publish only sanitized reports after reviewing them for addresses, hostnames, command output, and other sensitive information.
